# Academic and Industry References / Akademik ve Endüstriyel Kaynaklar

## Purpose / Amaç

This file documents the official industry security standards, academic frameworks, and documentation repositories used to design and validate the WAF validation rules.
Bu dosya, WAF doğrulama kurallarını tasarlamak ve doğrulamak için kullanılan resmi endüstri güvenlik standartlarını, akademik çerçeveleri ve dokümantasyon kaynaklarını listeler.

## Resources and Links / Kaynaklar ve Bağlantılar

1. **OWASP Top 10:2021 Core Guidelines**
   - **URL:** https://owasp.org/www-project-top-ten/
   - **Description:** Provided the foundational threat classification for modern web applications, specifically focusing on A03:2021-Injection vulnerabilities.
   - **Açıklama:** Modern web uygulamaları için temel tehdit sınıflandırmasını sağlamıştır; özellikle A03:2021-Injection (Enjeksiyon) açıklarına odaklanılmıştır.

2. **PortSwigger Web Security Academy**
   - **URL:** https://portswigger.net/web-security
   - **Description:** Used as a primary reference for advanced filter evasion techniques, double-encoding bypasses, and context-aware XSS exploitation mechanics.
   - **Açıklama:** Gelişmiş filtre atlatma teknikleri, çift kodlama (double-encoding) bypassları ve bağlam duyarlı XSS sömürü mekanizmaları için ana referans olarak kullanılmıştır.

3. **NIST Special Publication 800-53 (SI-10: Information Input Validation)**
   - **URL:** https://csrc.nist.gov/
   - **Description:** Federal information security standard utilized to establish corporate-level compliance requirements for systemic input field validation routines.
   - **Açıklama:** Sistemik girdi alanı doğrulama rutinleri için kurumsal düzeyde uyumluluk gereksinimlerini belirlemek amacıyla yararlanılan federal bilgi güvenliği standardıdır.

4. **MITRE ATT&CK Framework (T1190 & T1059)**
   - **URL:** https://attack.mitre.org/
   - **Description:** Referenced to analyze real-world adversarial behaviors regarding public-facing application exploitation and command/scripting interpreters.
   - **Açıklama:** İnternete açık uygulamaların sömürülmesi ve komut/betik yorumlayıcılarına yönelik gerçek dünya saldırgan davranışlarını analiz etmek için referans alınmıştır.

5. **Python 3.12 Core Documentation (re, html, urllib.parse)**
   - **URL:** https://docs.python.org/3/
   - **Description:** Technical reference guidelines for safely deploying regular expressions, sanitizing HTML entities, and breaking down complex URI components.
   - **Açıklama:** Düzenli ifadeleri güvenli bir şekilde uygulamak, HTML varlıklarını temizlemek ve karmaşık URI bileşenlerini ayrıştırmak için teknik kılavuz kaynaklarıdır.
